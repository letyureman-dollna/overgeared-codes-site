Which Overgeared Is This?

This site covers only the Roblox game Overgeared [BETA] by Overgeared Studios — an island-hopping action RPG inspired by the Korean web novel.

Fandom's "Overgeared Wiki" (Behen Archipelago, 66 islands) documents the novel, not this game. Overgeared Hero: Merge RPG is a separate mobile game — its codes don't work here.
